# Show a card from the first deck

Fork of [AnkiDroid](https://github.com/ankidroid/Anki-Android) (GPL-3.0).

## What was added

On the deck list (home screen), toolbar and overflow menu:

**Show card from first deck** / **Карточка из первой колоды**

It selects the first user deck in list order (skips empty Default and filtered decks) and opens the study screen with a card.

## How to use

1. Import your `.apkg` (for example `Words_Petrov_RU.apkg`).
2. Open the deck list.
3. Tap the flashcard icon in the top bar, or the menu item.

## Build

This repo is source only. Open it in **Android Studio**, let Gradle sync, then Run on a phone or emulator.

Official docs: https://github.com/ankidroid/Anki-Android/wiki/Development-Guide
