# Show a card from the first deck

Fork of [AnkiDroid](https://github.com/ankidroid/Anki-Android) (GPL-3.0).

## What was added

On the deck list (home screen), toolbar and overflow menu:

**Show card from first deck** / **Карточка из первой колоды**

It selects the first user deck in list order (skips empty Default and filtered decks) and opens the study screen with a card.

## How to use

Русская инструкция: **[ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)**

1. Install the APK from [Releases](https://github.com/Mr-HotIce/AnkiDroid/releases/tag/first-deck-2).
2. Import [decks/Words_Petrov_RU.apkg](decks/Words_Petrov_RU.apkg).
3. Open the deck list.
4. Tap the flashcard icon in the top bar, or the menu item.

## Build

Open this repo in **Android Studio** (or `gradlew :AnkiDroid:assembleFullDebug` with SDK on `D:\Android\Sdk`), then install the APK.

Official docs: https://github.com/ankidroid/Anki-Android/wiki/Development-Guide
